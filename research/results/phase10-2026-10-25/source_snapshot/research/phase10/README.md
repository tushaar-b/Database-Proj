# IntelliVest Phase 10

Research-only equal-constraint and observed-trade-off evaluation. No original policy, application source, PostgreSQL data or previous output is modified.

Start with [the final report](../results/phase10-2026-10-25/PHASE10_FINAL_REPORT.md) and [the executed run README](../results/phase10-2026-10-25/README.md). All modules honor `INTELLIVEST_PHASE10_OUT`; use a fresh directory for reproduction. Saved Phase 8/9 data are read-only inputs.

The Phase 10 integer reference is a separately versioned evaluation comparator with binary purchase-indicator grandfathering and norm supporting cuts. V3/V4 are unchanged. Scalar objectives, caps, similarities and experimental design are recorded before the grid in PROTOCOL.json; descriptive strata/block settings are recorded separately. No V6 or live policy improvement is introduced.

The results support a strong original-baseline execution improvement and quantify utility/diversification/latency trade-offs. They do not establish general optimization novelty, a global Pareto frontier, independent validation or universal greedy dominance.
