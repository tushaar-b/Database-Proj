# IntelliVest System Architecture & Design Specification

## Overview
IntelliVest is an affordability-driven, closed-loop financial analytics platform with dual PostgreSQL databases, a FastAPI Application Gateway, and a React dashboard interface.

---

## 1. Dual-Database Paradigm

### A. Advisory Database (`advisory_db`)
- **Nature**: ACID write-heavy relational operational store.
- **Key Tables**:
  - `USER_PROFILE`: Investor UUID, name, email, password hash, and risk tolerance classification (`CONSERVATIVE`, `MODERATE`, `AGGRESSIVE`).
  - `INCOME_STREAM`: Incomes categorized by frequency (`MONTHLY`, `YEARLY`).
  - `EXPENSE_ITEM`: Granular expenses partitioned into mandatory vs. discretionary.
  - `SURPLUS_SNAPSHOT`: Computed Surplus and Investable Buffer logs.
  - `RECOMMENDATION_LOG`: Stock allocation recommendations with status tracking (`PENDING`, `ACCEPTED`, `REJECTED`).

### B. Portfolio Risk Database (`risk_db`)
- **Nature**: Analytical relational store optimized for PostgreSQL window computations and time-series quotes.
- **Key Tables**:
  - `PORTFOLIO`: User portfolio records, valuation, cash balances, and target HHI limits.
  - `SECURITY_MASTER`: Security identifiers, tickers, sector taxonomies, exchanges, and beta values.
  - `HOLDING`: Real-time stock units and weighted average buy prices.
  - `TRANSACTION_LEDGER`: Append-only ledger of `BUY`, `SELL`, and `AUTO_REBALANCE` actions.
  - `DAILY_MARKET_QUOTE`: 5-year OHLCV daily pricing records indexed on `(security_id, trade_date DESC)`.
  - `REBALANCE_ALERT`: Threshold breach records with partial indexing on active alerts.
  - `mv_daily_sector_concentration`: Materialized view of sector Herfindahl-Hirschman Index (HHI).

---

## 2. In-Engine PostgreSQL Risk Analytics
All quantitative financial risk metrics are calculated natively inside PostgreSQL:
1. **30-Day Rolling Volatility**: `STDDEV(daily_return)` over a 30-day window.
2. **95% Parametric Value-at-Risk (VaR)**: $1.645 \times \sigma_{\text{portfolio}} \times V_{\text{portfolio}}$.
3. **Historical VaR**: `PERCENTILE_CONT(0.05)` over 252 trading days.
4. **Sharpe Ratio**: Annualized risk-adjusted excess returns.
5. **Herfindahl-Hirschman Index (HHI)**: $\sum (w_{\text{sector}})^2$ for sector diversification.

---

## 3. Concurrency & Closed-Loop Control
- **SERIALIZABLE Isolation**: Multi-asset rebalancing logic runs under strict serializable isolation to prevent write-skew and negative cash balance anomalies.
- **Feedback Loop**: When risk thresholds are violated, drift triggers automatically downscale recommendation limits generated by the sizing engine.
